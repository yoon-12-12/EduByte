# EduByte

시험 및 자격증 학습을 위한 통합 학습 플랫폼

배포 주소:
https://yoon-12-12.github.io/EduByte/

---

## 프로젝트 소개

EduByte는 자격증 및 시험 준비를 위한 학습 지원 웹 애플리케이션입니다.

사용자는 시험별 학습 자료를 확인하고,
모의고사를 풀며,
오답을 복습하고,
학습 통계를 확인할 수 있습니다.

---

## 주요 기능

### 시험 관리

- 시험 목록 조회
- 시험 상세 정보 확인
- 시험별 학습 노트
- 시험별 모의고사

지원 시험

- 정보처리기사
- SQLD
- ADsP
- 컴퓨터활용능력 1급

---

### 모의고사

- 객관식 문제 풀이
- 정답 확인
- 해설 제공
- 점수 계산
- XP 획득

---

### 오답노트

- 자동 오답 저장
- 오답 문제 다시 풀기
- 위험도 기반 복습
- 복습 통계 제공

---

### XP 시스템

- 문제 풀이 XP 획득
- 레벨 시스템
- XP 부스터
- XP 상점
- 아이템 구매

---

### 학습 분석

- Dashboard 통계
- 평균 점수
- 최고 점수
- 정답률
- 합격률
- 시험별 정확도

---

### 학습 기록

- 학습 캘린더
- 연속 학습 스트릭
- 누적 학습 일수

---

### 데이터 관리

- 전체 초기화
- LocalStorage 기반 데이터 저장

---
